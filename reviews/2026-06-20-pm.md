# Product & UX Review — 2026-06-20

## High Priority

| # | Area | Finding | Suggestion |
|---|------|---------|------------|
| 1 | Home | Dropdown doesn't scale past ~12 entries; breaks sacred visual theme (renders as native OS UI) | Replace with scrollable card grid (title + composer + thumbnail, click to enter) + search input |
| 2 | Home | No persistent indicator of which kirtan is loaded mid-session | Small always-visible label top-left: "Tulasī Āratī — Verse 3 / 7" |
| 3 | Display | Auto-scroll starts paused with no affordance; control bar hides in 3.5s leaving frozen screen | Auto-play on entry, or keep control bar visible until first user interaction |
| 4 | Display | Control bar hides after 3.5s — too fast for a priest mid-ritual | Increase to 6–8s, or only start timer after Play is pressed |
| 5 | Display | No verse progress indicator | "3 / 7" counter or progress bar along top edge |
| 6 | Features | No loop mode — Mahā-mantra chanted for 20–30 min continuously | Loop toggle: auto-scroll back to top when end is reached |
| 7 | Features | No "pin/repeat verse" for call-and-response kirtan | Long-press or button to lock view on current verse |
| 8 | Mobile | Control bar has no `flex-wrap` — overflows and clips on phone | Add `flex-wrap: wrap` + mobile breakpoint at 768px |
| 9 | Mobile | No media queries at all in style.css | Add `@media (max-width: 768px)` — reduce button size, collapse speed/font controls |
| 10 | Content | Only Jaya Rādhā Mādhava + Tulasī Āratī have translations confirmed | Complete translations for all 8 manifest kirtans |
